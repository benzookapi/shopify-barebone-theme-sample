Lesson 01 / 06

Start with the page frame

The home page and a product page share a layout. Shopify inserts the selected template at content_for_layout, between the header and footer groups.

!

Common pitfall

A home-page edit shows up on product pages

Content written directly in layout/theme.liquid appears on every page using that layout. Put a home-only module in a section referenced by templates/index.json.

Try it

From the sample directory, run shopify theme dev --store your-store.myshopify.com with your own store domain. Open the preview and move from home to a product. Which parts of the frame stay in place?

Lesson 02 / 06

Read a JSON template in display order

In templates/index.json, each entry in sections has an instance ID and a type naming its section file. The order array tells Shopify which instance comes first.

!

Common pitfall

The section name looks right, but the reference fails

The instance my_home has type home_page. Use my_home in order and follow the type to sections/home_page.liquid.

Try it

Predict which section will move to the top when the order is reversed. Check the preview, then find both instance IDs in the home template.

Lesson 03 / 06

Find a section in the theme editor

A section combines storefront markup and an editor schema. In home_theme_blocks.liquid, the schema offers a preset, allows the home template (index), and limits the section to one instance.

!

Common pitfall

The file exists, but “Add section” doesn’t offer it

Check the preset, the template or section group you are editing, and the instance limit. This sample already places the theme block examples section on the home page.

Try it

In the theme editor, open the existing theme block examples section on the home page and change its title. Compare the result with section.settings.title in the section file.

Lesson 04 / 06

Choose a block or a snippet

Start with the editing experience. The sample shows a local block inside home_page.liquid and a reusable link card inside home_theme_blocks.liquid. Both sections also call the same title snippet.

!

Common pitfall

The card exists in blocks/, but never appears

For the link card in this sample, the parent accepts @theme and renders children with content_for 'blocks'. The template also needs a card instance, which a merchant can add from the card’s preset.

Try it

On the home page, edit the label of one link card. The other card keeps its own label. Find both instances of link_card in index.json.

Lesson 05 / 06

Trace a breadcrumb back to its data

A product can belong to several collections. Add the Breadcrumbs section to the header group. On product pages the sample tries each source in order until it finds a usable trail.

!

Common pitfall

A product has a category, but the trail is shallow

The taxonomy path needs at least one collection handle matching a category ID. With no match, the snippet tries custom.breadcrumb_collections, then the menu. If neither supplies ancestors, the trail ends at Home › page title.

Try it

Choose a product with a category. Compare the category ID with its collection handle, then check which source supplied the first clickable ancestor. On the home page this section intentionally renders nothing.

Lesson 06 / 06

Check where a visibility rule applies

The optional filtered collection and search sections compare the customer’s custom.access_code with each product’s custom.access_codes list before rendering a card.

!

Common pitfall

A hidden card is mistaken for a purchase restriction

The filter runs in those two listing sections. A direct product page has its own rendering logic. A purchase restriction needs separate enforcement at cart and checkout, outside this theme sample.

Try it

In a development theme, replace the default collection listing with the filtered section. Compare a signed-out visit with a customer whose code matches a product, then check the same product’s own page.

Troubleshooting

Common
questions.

Can I preview the actual storefront on GitHub Pages?

Pages serves this guide and its diagrams. To render Liquid with store data, run shopify theme dev from the sample directory and open the CLI preview URL. For an installed theme you can revisit later, use shopify theme push --unpublished.

Preview setup ↗
Why do several products change when I edit one template?

Products assigned to the same template share its section configuration. For a different structure, create an alternate such as product.featured.json and assign it to the intended product. For a different value in the same structure, connect a compatible setting to a product metafield using a dynamic source.

Dynamic sources ↗
I changed a default in the schema. Why is the old title still there?

An existing section can have a saved value. For example, the home template already sets the title for theme_block_examples. Inspect that instance in the theme editor and change its saved title.

Home template ↗
Why is my local variable blank inside a snippet?

The render tag gives the snippet its own local scope. Pass a variable as a named argument. The breadcrumb section does this with menu_handle: section.settings.menu_handle.

See the render call ↗
Does allowing @app automatically add an app block?

The schema makes a section eligible to host app blocks. A compatible installed app must supply the block, and the merchant adds it in the theme editor. The home theme block section renders its children at content_for 'blocks'.

App blocks ↗
Why do extra products still appear after adding the filtered section?

The default collection and search templates already contain standard listing sections. If both a standard and a filtered section are present, each renders its own results. Inspect the template in the theme editor and remove or hide the standard listing for this exercise.

Filtered storefront setup ↗
The editor still shows the old version. Where do I check first?

Check the store and theme in the CLI output and open the editor URL for that development theme. Look for sync or schema errors. If the correct preview remains stale after a successful sync, restart shopify theme dev and use the URL it prints.
